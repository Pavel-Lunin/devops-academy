# Шаблоны

Все файлы ниже — **шаблоны-черновики**, не подготовленные уроки, задания или результаты студента. Плейсхолдеры в двойных фигурных скобках заменяются при создании настоящего материала; не копировать пустые шаблоны во все будущие модули.

| Шаблон | Для чего |
|---|---|
| [module-syllabus.md](module-syllabus.md) | План модуля, оглавление и prerequisites |
| [lesson.md](lesson.md) | Одно микрозанятие |
| [lab.md](lab.md) | Самостоятельная lab без решения |
| [environment.md](environment.md) | Спецификация Linux/ARM64 и изоляции |
| [interview-question.md](interview-question.md) | Один вопрос без ответа |
| [interview-answer-key.md](interview-answer-key.md) | Отдельный авторский ключ |
| [interview-result.md](interview-result.md) | Только фактический ответ и объяснимая оценка |
| [mini-interview.md](mini-interview.md) | Короткая проверка раздела |
| [module-exam.md](module-exam.md) | Итоговая проверка модуля |
| [incident-note.md](incident-note.md) | Личная заметка студента об ошибке |
| [verification-report.md](verification-report.md) | Фактическая проверка материала / инструмента |

До регистрации свериться с [ID и статусами](../docs/material-conventions.md), до назначения времени — с [бюджетом](../docs/time-budget.md). Ответы и решения хранить отдельно от заданий; личные записи заполняет студент.
