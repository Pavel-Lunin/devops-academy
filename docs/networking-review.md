# Проверка первой партии Networking — 2026-10-18

Статус: **проверено** в указанном объёме. Авторский этап 04, не учебное занятие.

## Подготовлено

Три полнотекстовых урока [A-M02-S01](../curriculum/A-M02-networking/SYLLABUS.md#a-m02-s01), одна трёхчасовая [lab](../labs/LAB-A-M02-S01-01-network-path/README.md), [ENV-01](../labs/environments/ENV-01-offline-network.md). Восемь полных Q-карточек, шесть базовых вопросов и два диагностических кейса; ключи и разбор отдельно. [Ровно одна демонстрация оценки](../interviews/examples/evaluation-demo.md) явно авторская, не результат студента.

## Фактическая проверка

- macOS ARM64, Python 3.9: авторские `layers` и `subnet 192.0.2.139/26` выполнены в памяти, без сетевых вызовов и изменения ресурсов. Это примеры с другими условиями, не выполнение lab.
- Пять регрессионных тестов вычислительного примера: вложенность, граница /26, /0 без огромного списка, /31 и /32, неверный IPv4/префикс/IPv6. 23 теста интервью проходят с новыми карточками; 7 самотестов структурного аудитора проверяются отдельно.
- Перечитаны три урока, задания и ключи: определения перед использованием, конкретные prerequisites, независимое предъявление, отсутствие ответов в вопросах; диагностический HTTP-вопрос перенесён за границу первой темы заменой на индикатор кабеля.
- W03 =180/60/180/60=480 мин; короткие опыты и чтение включены. 130×3 мин уроков +30 мин оставшегося интервью +60 D =480. Реальная скорость ученика не измерялась; резерв описан в бюджете.
- D05: URL и текст §1.1.1, §1.1.3; D06: URL и текст The Problem, Packet Generation/Reception доступны бесплатно без входа. Проверены 2026-10-18. Это старые базовые RFC, не проверка всех современных протоколов.

## Ограничения и продолжение

Это пригодная к чтению и самостоятельному разбору офлайн-модель, а не Linux VM и не живой сетевой стенд. Не запускались пользовательские задания, сетевые команды хоста, Linux `ip`/`ss`, packet capture и настройка интерфейсов. Подтверждать их навык по этой партии нельзя. Новых непроверенных внешних URL в уроках нет; общий реестр содержит исторические непроверенные R09/R10.

S02–S04 пока остаются syllabus; следующие партии получают отдельный отчёт. Полноценные уроки A-M01 ещё не написаны: маршрут курса начинается с диагностики A-M01-S01-L01, наличие сетевых материалов её не обходит. Все личные ответы, оценки, часы, даты повторения и подтверждённые навыки остаются пустыми.

Проверки воспроизводятся из корня: `python3 -B scripts/check_curriculum.py --self-test`, `python3 -B -m unittest discover -s scripts -p 'test_*.py'`, `git diff --check`. Они проверяют автора и структуру, не освоение студентом.
