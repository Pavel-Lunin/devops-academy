# Реестр источников

Дата фактической проверки: **2026-10-18**. Локальные расшифровки прочитаны в предыдущем шаге и повторно сверены на сохранность; исходные файлы не изменялись. Веб-проверка выполнена инструментом чтения источников, без визуального тестирования во встроенном браузере.

**«Проверено» здесь означает: URL открылся, получены текст/оглавление, подтверждена доступность указанного раздела/темы.** Это не runtime-проверка команды, не проверка всех дочерних страниц, бесплатности всего сервиса или ARM64-образов. Даты публикации не выдумываются; /current, /latest, /stable не фиксируют установленную версию.
