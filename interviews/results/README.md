# Только фактические результаты

Интервью не проводились; ответов, оценок и дат студента здесь нет. Синтетические записи для тестов инструментов — только во временных каталогах тестов.

Один фактический ответ — один RES-YYYY-MM-DD-NNN.md по [шаблону](../../templates/interview-result.md). Обязательны ID вопроса, локальная дата, J0/J1/M, этап, оценка 0–3 с основанием, реальный ответ/согласованная выдержка, неполнота/ошибка, подсказки и следующее действие. Не создавать результат, если ответа не было.

Этапы: initial, review-7, review-30, mixed. У initial/mixed базовая проверка — «—»; у review — ID исходного initial. Сроки хранятся в [реестре](../review-schedule.md); mixed не закрывает их автоматически. Первичный балл после разбора не переписывать, ответ после полного решения не выдавать за самостоятельный.

Ментор записывает только фактически сказанное/показанное с объяснением оценки; личные выводы студент пишет сам. «Пройдено» требует отдельно доказательств и согласия. Секреты, корпоративные данные и личные логи в записи не попадают.
