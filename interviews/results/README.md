# Результаты интервью

Статус: **каркас**. Интервью не проводились, ответов и оценок нет.

После фактической проверки создавать Markdown-запись: дата, ID вопроса, ответ студента или согласованная точная выдержка, оценка 0–3, объяснение оценки, подсказки, исправление ошибки и ссылка на повторение. Студент пишет ответ сам; ментор не сочиняет его задним числом.

Даты следующей проверки хранятся в [едином расписании](../review-schedule.md), а не дублируются в нескольких таблицах. Изменение статуса освоения в [PROGRESS.md](../../PROGRESS.md) требует доказательств и согласия студента.
