# INT-B-M06-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-B-M06-S01-01 | Исходник/проверки/идентичность/конфигурация/runtime и пользовательский результат. |
| Q-B-M06-S01-02 | Допустимая потеря данных во времени и целевое время восстановления; фактические значения измеряются отдельно. |
| Q-B-M06-S01-03 | Ограниченная цель, scope, stop condition, recovery и явное разрешение риска. |
| Q-B-M06-S01-04 | Восстановление воздействия и устранение причины могут разделяться по времени. |
| Q-B-M06-S01-05 | Проверенная хронология, contributing factors и проверяемые действия без обвинений. |
| Q-B-M06-S01-06 | Только наличие файла; восстановимость не доказана, нужны причина/проверка данных. |
| Q-B-M06-S01-07 | Сохранить evidence/данные и выбрать согласованный recovery по совместимости, не откатывать дальше вслепую. |
| Q-B-M06-S01-08 | Реальная цель и budget ресурсов определяют состав; интеграция не требует максимальной сложности. |
