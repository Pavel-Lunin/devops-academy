# INT-B-M02-S01 — критерии после ответа

Статус: **черновик авторского ключа**. Не показывать и не читать при постановке вопросов. Это не ответы студента и не результат проверки.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Не требовать дословного воспроизведения. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-B-M02-S01-01 | Соответствие желаемому состоянию и работоспособность различаются. |
| Q-B-M02-S01-02 | Откуда брать конфигурацию и к каким cluster/scope её применять. |
| Q-B-M02-S01-03 | Проверка/сборка артефакта и контролируемое изменение ссылки, не бесконтрольные права deploy. |
| Q-B-M02-S01-04 | Возврат расхождений и удаление отсутствующих в desired state ресурсов имеют разный риск. |
| Q-B-M02-S01-05 | Контроллер снова согласует с Git; источник желаемого состояния должен быть понятен. |
| Q-B-M02-S01-06 | Источник desired state и reconciliation, не пытаться бесконечно перебивать контроллер. |
| Q-B-M02-S01-07 | Рендер, revision, scope/права, destination и фактические события. |
| Q-B-M02-S01-08 | Начать с явного scope и наблюдений; destructive удаление требует отдельного решения. |

Уточнение при неполном ответе: попросить объяснить причинную связь или предложить безопасное наблюдение; не выдавать сразу весь ключ. В результате записать фактическую помощь. Полный разбор — после попытки и по запросу.

Технические первоисточники: [D33](https://argo-cd.readthedocs.io/en/stable/getting_started/), [D32](https://helm.sh/docs/chart_template_guide/); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
