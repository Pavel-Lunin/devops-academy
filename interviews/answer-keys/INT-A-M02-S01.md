# INT-A-M02-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M02-S01-01 | Host может иметь несколько интерфейсов и адресов; интерфейс — точка подключения. |
| Q-A-M02-S01-02 | Доставка кадров в сегменте и выбор IP-маршрута между сетями. |
| Q-A-M02-S01-03 | Разделить ответственность и сузить поиск по наблюдениям, не декламировать названия. |
| Q-A-M02-S01-04 | Полезная нагрузка получает заголовки уровней; кадр, пакет и сегмент различаются. |
| Q-A-M02-S01-05 | Сопоставляет локальный next-hop IP с MAC, а не ищет удалённый сервер через интернет. |
| Q-A-M02-S01-06 | MAC локального next hop; MAC конечного удалённого host не требуется. |
| Q-A-M02-S01-07 | Физическое наблюдение не доказывает IP/прикладной обмен; нужны разные гипотезы и различающие наблюдения, не единственная угаданная причина. |
| Q-A-M02-S01-08 | Рабочая модель пути с точными ролями; названия помогают проверять гипотезы, не заменяют их. |


Технические первоисточники: [D05](https://datatracker.ietf.org/doc/html/rfc1122), [D06](https://www.rfc-editor.org/rfc/rfc826); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
