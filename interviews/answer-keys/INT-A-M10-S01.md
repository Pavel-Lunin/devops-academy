# INT-A-M10-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M10-S01-01 | Версия/идентичность и заданный пользовательский результат, не только процесс running. |
| Q-A-M10-S01-02 | Несколько целевых наблюдений по слоям и проверяемая гипотеза. |
| Q-A-M10-S01-03 | Отдельный restore, проверка схемы/данных и фактическое время. |
| Q-A-M10-S01-04 | Impact, факты/время, действия/результаты, гипотеза и следующий шаг без секретов. |
| Q-A-M10-S01-05 | Наблюдаемое выполнение, объяснение и степень самостоятельности. |
| Q-A-M10-S01-06 | Ready/dependency/route/input и наблюдения, не ложное заключение по health. |
| Q-A-M10-S01-07 | Совместимость схемы/данных и отдельный recovery, сохранить evidence. |
| Q-A-M10-S01-08 | Явно закрыть фундамент/пересмотреть сроки, не прятать пробел за новыми инструментами. |
