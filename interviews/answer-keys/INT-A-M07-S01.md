# INT-A-M07-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M07-S01-01 | Цели и область применения, которые нужно проверить до запуска. |
| Q-A-M07-S01-02 | Контракт состояния/аргументов может давать предсказуемость; shell требует собственного контроля. |
| Q-A-M07-S01-03 | Повторное приведение к тому же состоянию без лишнего изменения, не просто exit zero. |
| Q-A-M07-S01-04 | Реакция на изменение и воспроизводимая конфигурация с управляемыми значениями. |
| Q-A-M07-S01-05 | Реальный postcondition и поддержку всех задач; diff также может раскрывать значения. |
| Q-A-M07-S01-06 | Неидемпотентная операция, нестабильный input/template, неверный changed_when; нужна независимая проверка. |
| Q-A-M07-S01-07 | Результат сервиса, scope/variables/handler и наблюдения на target, не статус automation alone. |
| Q-A-M07-S01-08 | Минимальное реальное повторение на двух hosts; абстракция оправдывается проверенными потребностями. |
