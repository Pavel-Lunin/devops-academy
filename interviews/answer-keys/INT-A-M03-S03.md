# INT-A-M03-S03 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M03-S03-01 | Каталог может показывать другую filesystem; важна фактическая смонтированная область. |
| Q-A-M03-S03-02 | Разные наблюдения filesystem/доступных файлов, открытые удалённые файлы и mounts. |
| Q-A-M03-S03-03 | Возможны inode/квота/метаданные; проверить конкретный ресурс. |
| Q-A-M03-S03-04 | Очередь/ожидания задач и занятость вычисления не одно измерение. |
| Q-A-M03-S03-05 | Cache и reclaimable память требуют контекста процесса/времени, не одной цифры. |
| Q-A-M03-S03-06 | Bytes/inodes/quota/mount и размер учебных логов; не удалять общий state. |
| Q-A-M03-S03-07 | Ограничения и OOM/exit/journal в госте, сопоставить по времени. |
| Q-A-M03-S03-08 | Минимально нужные безопасные свидетельства и быстрый recovery по impact; не затягивать без причины. |


Технические первоисточники: [D02](https://www.debian.org/doc/manuals/debian-handbook/), [D01](https://www.debian.org/doc/manuals/debian-reference/ch01.en.html); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
