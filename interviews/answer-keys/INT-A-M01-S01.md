# INT-A-M01-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M01-S01-01 | Разные границы ОС/ядра; место команды и изоляция важнее похожего терминала. |
| Q-A-M01-S01-02 | Путь разрешается от cwd; абсолютный путь задаётся от корня. |
| Q-A-M01-S01-03 | Два потока данных и отдельный код результата; перенаправления не равны успеху. |
| Q-A-M01-S01-04 | Исполняемый бит, доступ к каталогам и корректный интерпретатор; не один факт существования. |
| Q-A-M01-S01-05 | Наследование окружения ограничено; PATH и export влияют на поиск/дочерние процессы. |
| Q-A-M01-S01-06 | Доступ по всему пути, execute bit и mount-ограничения; не советовать chmod 777. |
| Q-A-M01-S01-07 | PATH, shell/environment, cwd и место исполнения; сравнить наблюдения без изменения хоста. |
| Q-A-M01-S01-08 | Нужные kernel/systemd/network возможности и граница риска; не выбирать по привычке. |


Технические первоисточники: [D01](https://www.debian.org/doc/manuals/debian-reference/ch01.en.html), [D02](https://www.debian.org/doc/manuals/debian-handbook/); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
