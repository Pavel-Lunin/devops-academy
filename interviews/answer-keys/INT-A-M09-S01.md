# INT-A-M09-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M09-S01-01 | Вычисления, связность и доступ — разные объекты/ответственности; описать схему. |
| Q-A-M09-S01-02 | Описание и взаимодействие с системой против соответствия управляемых объектов. |
| Q-A-M09-S01-03 | Подготовка, предлагаемый diff и применение; ни plan, ни файл HCL не равны созданной инфраструктуре. |
| Q-A-M09-S01-04 | Содержат данные/значения и связи ресурсов; не должны попадать в Git как безобидный cache. |
| Q-A-M09-S01-05 | HCL/lifecycle/state на локальной модели; не cloud IAM/network и удалённый deploy. |
| Q-A-M09-S01-06 | Адрес/входы/lifecycle и последствия до apply; не подтверждать автоматически. |
| Q-A-M09-S01-07 | Связанные disk/IP/сервисы и биллинг по конкретному провайдеру; отсутствие VM не полная очистка. |
| Q-A-M09-S01-08 | Нет; чтение и локальная модель закрывают заявленный J1, реальный cloud опыт остаётся непроверенным. |
