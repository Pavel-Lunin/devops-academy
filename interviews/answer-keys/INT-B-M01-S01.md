# INT-B-M01-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-B-M01-S01-01 | Набор разрешений и назначение субъекту; область действия зависит от binding. |
| Q-B-M01-S01-02 | Существуют общие cluster-level объекты, сеть, ресурсы и привилегии. |
| Q-B-M01-S01-03 | Планирование, ограничение и бюджет scope имеют разные эффекты. |
| Q-B-M01-S01-04 | Подключение/политика сети зависят от фактического плагина; манифест не гарантирует enforcement. |
| Q-B-M01-S01-05 | Предоставленное storage, запрос workload и интерфейс/драйвер; жизненные циклы различаются. |
| Q-B-M01-S01-06 | Все bindings/агрегированные права и scope; не ограничиваться одной Role. |
| Q-B-M01-S01-07 | Requests/quota/scheduling/storage и events; не считать scaling мгновенной ёмкостью. |
| Q-B-M01-S01-08 | Определить необходимые действия и минимальный scope; удобство не отменяет границу риска. |
