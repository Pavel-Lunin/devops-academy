# INT-A-M02-S02 — критерии после ответа

Статус: **черновик авторского ключа**. Не показывать и не читать при постановке вопросов. Это не ответы студента и не результат проверки.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Не требовать дословного воспроизведения. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M02-S02-01 | Адрес интерфейса и границу сети/host; gateway не выводится автоматически из маски. |
| Q-A-M02-S02-02 | Область использования и достижимость; private не синоним автоматически безопасного. |
| Q-A-M02-S02-03 | У сети host-биты нулевые, у broadcast обычной подсети — единицы; применить маску и сравнить сетевую часть, показать расчёт. |
| Q-A-M02-S02-04 | Next hop для направлений без более специфичного подходящего маршрута. |
| Q-A-M02-S02-05 | Выбор пути, преобразование адресов и выдача конфигурации; функции независимы. |
| Q-A-M02-S02-06 | Маску, маршрут, gateway, DNS и ограничения; выдача адреса не проверяет весь путь. |
| Q-A-M02-S02-07 | Несовпадающие маски/сегменты, маршрут и фильтрация; не судить по первым октетам. |
| Q-A-M02-S02-08 | Нет; read-only наблюдение и отдельный разрешённый гостевой стенд ограничивают риск. |

Уточнение при неполном ответе: попросить объяснить причинную связь или предложить безопасное наблюдение; не выдавать сразу весь ключ. В результате записать фактическую помощь. Полный разбор — после попытки и по запросу.

Технические первоисточники: [D05](https://datatracker.ietf.org/doc/html/rfc1122), [D02](https://www.debian.org/doc/manuals/debian-handbook/); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
