# INT-A-M03-S02 — критерии после ответа

Статус: **черновик авторского ключа**. Не показывать и не читать при постановке вопросов. Это не ответы студента и не результат проверки.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Не требовать дословного воспроизведения. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M03-S02-01 | Шанс штатного завершения против принудительной остановки без обработчика. |
| Q-A-M03-S02-02 | Текущее состояние и поведение при загрузке; одно не следует из другого. |
| Q-A-M03-S02-03 | Процесс может жить без готовности зависимости или обработки запросов. |
| Q-A-M03-S02-04 | Границы аргументов и честный результат; учитывать pipeline и ошибочные пути. |
| Q-A-M03-S02-05 | Окружение, cwd/PATH, права и вывод; не полагаться на личный профиль. |
| Q-A-M03-S02-06 | Status, exit result, только учебный journal, executable/cwd/environment. |
| Q-A-M03-S02-07 | Не повторять разрушительное действие; синтетическая копия, аргументы/quoting и границы ввода. |
| Q-A-M03-S02-08 | Сложная структура/ошибки/тестирование могут оправдать маленький Python CLI, не переписывать всё автоматически. |

Уточнение при неполном ответе: попросить объяснить причинную связь или предложить безопасное наблюдение; не выдавать сразу весь ключ. В результате записать фактическую помощь. Полный разбор — после попытки и по запросу.
