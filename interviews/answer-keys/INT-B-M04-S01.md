# INT-B-M04-S01 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-B-M04-S01-01 | Выдача, ограничение доступа, доставка, ротация/отзыв и аудит; не только хранение. |
| Q-B-M04-S01-02 | Ограничить действия и время; auth и авторизация не одна функция. |
| Q-B-M04-S01-03 | Упрощённые гарантии/хранение/доступ, ограниченная учебная цель. |
| Q-B-M04-S01-04 | Состав зависимостей против связи исходника/процесса/артефакта; ни одно само не гарантирует безопасность. |
| Q-B-M04-S01-05 | Доверенный субъект/ключ/контекст, идентичность артефакта и ожидаемые гарантии. |
| Q-B-M04-S01-06 | Путь ввода/маскирования/команд и права; реальные токены не извлекать для повторения. |
| Q-B-M04-S01-07 | Остановить доверенное использование и установить источник/сборку, не игнорировать mismatch. |
| Q-B-M04-S01-08 | Нет; нужны соответствующие проверенные гарантии процесса и доверия, не один формат. |
