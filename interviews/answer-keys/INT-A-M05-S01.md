# INT-A-M05-S01 — критерии после ответа

Статус: **черновик авторского ключа**. Не показывать и не читать при постановке вопросов. Это не ответы студента и не результат проверки.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Не требовать дословного воспроизведения. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M05-S01-01 | Количественное время/событие/путь запроса; сигналы дополняют друг друга. |
| Q-A-M05-S01-02 | Накопление с возможным reset против текущего значения; анализ изменения требует контекста. |
| Q-A-M05-S01-03 | Доступность сбора target, не всю исправность host/API. |
| Q-A-M05-S01-04 | Каждая комбинация создаёт отдельные ряды; пользовательские идентификаторы быстро раздувают объём. |
| Q-A-M05-S01-05 | Сигнал реального условия с допустимым шумом, временем и понятным действием/runbook. |
| Q-A-M05-S01-06 | Datasource/query/time range/labels и scrape target; не переустанавливать всё сразу. |
| Q-A-M05-S01-07 | Проверить цель, duration/threshold и шум; не прятать настоящий отказ. |
| Q-A-M05-S01-08 | Для A сначала надёжный минимальный сигнал; расширение оправдать диагностической нуждой. |

Уточнение при неполном ответе: попросить объяснить причинную связь или предложить безопасное наблюдение; не выдавать сразу весь ключ. В результате записать фактическую помощь. Полный разбор — после попытки и по запросу.

Технические первоисточники: [D18](https://prometheus.io/docs/guides/node-exporter/), [D19](https://grafana.com/docs/grafana/latest/fundamentals/); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
