# Ключи ответов

Статус: **черновик авторских критериев**. Файлы `INT-<ID-раздела>.md` содержат критерии соответствующего банка и общую рубрику 0–3. Это не ответы студента; ментор использует их только после фактического ответа.

Будущий ключ имеет ID вопроса и создаётся из [отдельного шаблона](../../templates/interview-answer-key.md). Здесь хранятся тезисы хорошего ответа, допустимые варианты, ошибки, рубрика и уточнения для проверки после ответа студента.

Ментор не читает ключ при видимой постановке вопроса и не показывает его до фактического ответа. Отдельный каталог — защита от случайного просмотра, не пароль или шифрование. Не использовать свёрнутый блок ответа в том же файле вопроса.
