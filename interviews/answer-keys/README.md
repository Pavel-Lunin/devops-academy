# Критерии ответов

Каталог содержит авторские критерии для 17 модульных банков и подробно оформленные критерии Networking. Это материалы программы; записей фактических ответов здесь нет.

В ключах перечислены основные тезисы, типовые ошибки и рубрики, связанные с вопросами соответствующего ID. Полнотекстовые сетевые карточки расположены в [networking/](networking/), модульные банки — в файлах `INT-<ID-раздела>.md`.

Отдельная справочная выборка вопросов Linux из пользовательских изображений находится в [linux-image-reference.md](linux-image-reference.md).
