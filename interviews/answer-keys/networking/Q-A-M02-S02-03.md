# Q-A-M02-S02-03 — ключ после ответа

- ID: Q-A-M02-S02-03
- Статус: проверено
- Назначение: рубрика W04

## Тезисы хорошего ответа

Сетевые биты сохранены, host-биты нулевые для сети и единичные для broadcast обычной подсети; сравнить сетевые части; один сегмент физически не доказывает одинаковую маску.

## Распространённые ошибки

Назначать .0/.255 границами при любом префиксе; всегда вычитать2 для /31 и /32.

## Необязательное уточнение

Покажи промежуточный расчёт другой /27.

## Оценка 0–3

0 — понимание не показано; 1 — отдельные элементы при существенном пробеле; 2 — основные связи верны своими словами; 3 — самостоятельный новый вариант и различающая диагностика. Неполноту уточнять; подсказки учитывать; оценки и даты без реального ответа не создавать.
