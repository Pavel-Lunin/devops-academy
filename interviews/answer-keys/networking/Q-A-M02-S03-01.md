# Q-A-M02-S03-01 — отдельный ключ примера

- ID: Q-A-M02-S03-01
- Статус: черновик
- Назначение: пример
- Использование: только после фактического ответа; не читать при постановке вопроса.
- Источник: [D07](https://www.rfc-editor.org/rfc/rfc9293), проверено 2026-10-18; рубрика и формулировка авторские.

## Тезисы хорошего ответа

- В учебной модели конечной точки нужны адрес, порт и транспортный протокол; номер порта без контекста не определяет удалённое соединение.
- Сокет как объект API приложения не тождественен установленному TCP-соединению; у соединения есть обе конечные точки.
- Одинаковый числовой порт у TCP и UDP не означает одну и ту же службу.

## Распространённые ошибки

- Считать номер порта уникальным адресом приложения во всей сети.
- Смешивать порт, процесс и установленное соединение.

## Необязательное уточнение

Как изменится описание соединения, если к тому же серверному порту подключится второй клиент?

## Оценка 0–3

| Балл | Наблюдаемое основание |
|---|---|
| 0 | Ответа по существу нет либо студент прямо говорит «не знаю»; не стыдить, предложить объяснение и закрепление |
| 1 | Есть отдельный верный тезис, но существенная причинная ошибка или пробел из списка выше |
| 2 | Ключевые тезисы объяснены корректно своими словами; допустимые альтернативы не штрафуются |
| 3 | Корректный ответ дополнен собственным примером и самостоятельным различающим наблюдением/диагностикой |

Неполнота и фактическая ошибка фиксируются раздельно. Полный разбор после попытки не является самостоятельным ответом на 3; записать подсказки и проверить самостоятельность позже другим условием. Балл не означает автоматическое «пройдено». Это критерии автора, а не выставленная кому-либо оценка.
