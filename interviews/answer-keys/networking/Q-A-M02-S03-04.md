# Q-A-M02-S03-04 — отдельный ключ примера

- ID: Q-A-M02-S03-04
- Статус: черновик
- Назначение: пример
- Использование: только после фактического ответа; не читать при постановке вопроса.
- Источник: [D08](https://www.rfc-editor.org/rfc/rfc1034), проверено 2026-10-18; рубрика и формулировка авторские.

## Тезисы хорошего ответа

- Клиент обращается к настроенному средству разрешения; рекурсивный resolver выполняет поиск и может использовать кеш.
- Authoritative server отвечает за сведения своей зоны; его роль отличается от рекурсивного обслуживания клиента.
- Конкретный путь и наличие промежуточного кеша определяются средой; нельзя выдавать одну схему за все реализации.

## Распространённые ошибки

- Считать рекурсивный resolver владельцем всех DNS-зон.
- Говорить, что каждый запрос клиента обязательно доходит до authoritative server.

## Необязательное уточнение

Какие наблюдения нужны, чтобы понять происхождение ответа конкретному клиенту?
