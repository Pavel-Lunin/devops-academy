# INT-B-M01-S02 — критерии ответов

Статус: **черновик авторского ключа**. Содержит критерии и рубрики вопросов раздела.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-B-M01-S02-01 | Пакет шаблонов, входные параметры и установленный экземпляр/история. |
| Q-B-M01-S02-02 | Более приоритетные входы меняют рендер; проверять итог, не только defaults. |
| Q-B-M01-S02-03 | Убрать реальное повторение, сохранив объяснимый итоговый YAML. |
| Q-B-M01-S02-04 | Статические/рендерные свойства, не runtime готовность и корректность данных. |
| Q-B-M01-S02-05 | Возврат конфигурации/версии, который не откатывает все внешние эффекты. |
| Q-B-M01-S02-06 | Сопоставить итоговые labels/selectors/ports, а не только template syntax. |
| Q-B-M01-S02-07 | Итоговые values и manifests, precedence и историю, не полагаться на имя chart. |
| Q-B-M01-S02-08 | Только при доказанной повторяемости; минимальный chart легче независимо проверить. |
