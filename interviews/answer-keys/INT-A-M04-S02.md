# INT-A-M04-S02 — критерии после ответа

Статус: **черновик авторского ключа**. Не показывать и не читать при постановке вопросов. Это не ответы студента и не результат проверки.

Общая рубрика: 0 — понимание не показано; 1 — отдельные верные фрагменты с существенным пробелом; 2 — требуемые тезисы и причинная связь корректны; 3 — то же плюс собственный пример и самостоятельная диагностика. Не требовать дословного воспроизведения. Для сценария важна проверяемая последовательность гипотез, не угадывание одной причины.

| ID вопроса | Минимальные тезисы для корректного ответа / граница ошибки |
|---|---|
| Q-A-M04-S02-01 | Процесс/его окружение, связность и отдельное состояние; не одинаковые сущности. |
| Q-A-M04-S02-02 | Процесс может стартовать до готовности зависимости; нужны наблюдаемые критерии и обработка отказа. |
| Q-A-M04-S02-03 | Согласованные изменения и ожидаемая структура; connection не проверяет корректность схемы. |
| Q-A-M04-S02-04 | Учебные данные в отдельно понятном storage, а не случайном writable layer. |
| Q-A-M04-S02-05 | Восстановление в отдельную цель и проверка нужных данных/схемы, не наличие dump. |
| Q-A-M04-S02-06 | Последовательно проверить связность, готовность и безопасный класс ошибки без чтения секретов. |
| Q-A-M04-S02-07 | Неверный volume/mount/цель, новая БД; не выполнять prune/delete вслепую. |
| Q-A-M04-S02-08 | Нет; совместимость схемы и путь восстановления данных решаются отдельно. |

Уточнение при неполном ответе: попросить объяснить причинную связь или предложить безопасное наблюдение; не выдавать сразу весь ключ. В результате записать фактическую помощь. Полный разбор — после попытки и по запросу.

Технические первоисточники: [D12](https://docs.docker.com/compose/intro/compose-application-model/), [D15](https://www.postgresql.org/docs/current/backup.html); веб-страницы проверены 2026-10-18, ограничения — в resources/SOURCES.md. Рубрика составлена автором.
