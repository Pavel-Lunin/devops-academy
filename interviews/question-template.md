# Контракт карточки вопроса

Статус: черновик шаблона. Копируемый шаблон — [вопрос](../templates/interview-question.md); ключ создаётся отдельно по [шаблону](../templates/interview-answer-key.md).

| Поле | Требование |
|---|---|
| ID | Устойчивый Q-ID; детализация банка не создаёт второй ID |
| Статус / Назначение | Статус материала по соглашениям; назначение отдельно: «пример» либо рабочий вопрос |
| Модуль / Раздел / Уроки | Конкретные ID и ссылки на урок или его плановый якорь |
| Уровень | Ровно J0, J1 или M, без смешанного J0/J1 в рабочей карточке |
| Тип | definition, mechanism, troubleshooting, tradeoff |
| Проверяет | Нейтральная формулировка навыка, без тезисов ответа |
| Лаборатория | LAB-ID и существующая ссылка на задание/план либо «нет» |
| Минуты | Ответ/короткое уточнение внутри недельного часа |
| Происхождение | Автор Academy либо точный опубликованный список; не выдумывать опыт кандидатов |
| Источник | Первичный материал механизма, язык, доступ, дата и ограничения проверки |
| Вопрос / Условия | Одно задание без ответа; синтетические данные кейса обозначены явно |

Отдельный ключ содержит тезисы, распространённые ошибки, необязательное уточнение и рубрику 0–3. Не вставлять их в вопрос, свёрнутый блок, индекс или вывод средства показа. Примеры детализируют существующие Q-ID; остальные INT-банки — план до подготовки полного контракта.
