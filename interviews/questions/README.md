# Вопросы без ответов

Статус: **запланировано**. Реальных вопросов пока нет.

Создавать содержательные вопросы из [шаблона](../../templates/interview-question.md), привязывать к зарегистрированным ID раздела/урока и J0/J1/M. Типы: `definition`, `mechanism`, `troubleshooting`, `tradeoff`. Самостоятельно составленные вопросы маркировать как авторские, заимствованные — точным проверенным источником.

В формулировках и оглавлении не должно быть тезисов ответа; проверка вопроса на случайное раскрытие — часть авторского контроля. Ключ того же ID хранится отдельно, не вставляется в мини-интервью.
