# Промпт 05 — TachoApp: аудит DevOps, строго read-only

**ВНИМАНИЕ: запускать в рабочем каталоге TachoApp, а НЕ DevOps Academy.**

Ты опытный DevOps/Mobile Platform Engineer. Проведи **строго read-only аудит** текущего репозитория для поиска реально полезных инфраструктурных задач, которые могут развивать DevOps-компетенции автора проекта.

## Контекст и запреты

TachoApp — волонтёрский продукт для водителей и данных тахографов. Из предыдущего разговора известно о нативных Android/Kotlin и iOS/Swift клиентах. **Не предполагай**, что существуют backend, CI/CD, облако, отдельные сервисы и т.п. — только подтвердив файлами. Не путай TachoApp с React Native рабочим приложением.

**Запрещено:** менять файлы, конфигурации, Git, lock-файлы, запускать сборку и install, запускать тесты со side effects, создавать отчётные файлы здесь, читать/печатать значения секретов, загружать внешним сервисам код/конфигурации, делать deployment, commit/push или любые сетевые/платные действия. Разрешены только локальные команды чтения/поиска файлов в доступных границах репозитория. Если Codex требует разрешение на действие с изменением состояния — не выполняй.

## Проверить по фактическим файлам

1. Архитектура и модули: Android/iOS, есть ли серверы/скрипты/другие компоненты.
2. Git и релизы: версии, теги, ветки и PR-процессы лишь там, где есть документальные основания.
3. Android: Gradle/AGP/JDK/SDK, variants, unit/lint checks, APK/AAB, подпись — **не раскрывать значения ключей**.
4. iOS: Xcode schemes/configs, Swift Package Manager/CocoaPods, подпись/profiles — без вывода секретов.
5. CI/CD: найденные pipelines, runner/agent, stages, cache, artifacts, conditions, storage, deployment; отсутствие файла ≠ доказательство, что внешнего CI нет.
6. Безопасность: потенциальные риски секретов, permissions, dependency upgrades, сторонние actions.
7. Мониторинг и качество: crash reporting, тесты, логирование, доступные метрики.
8. Возможность повторяемых локальных/CI-сборок и их диагностики.

## Вывод

**Только сообщение в чат, никаких файлов в TachoApp**. Отчёт с разделами:
- Фактически обнаруженные компоненты и ссылки на пути файлов.
- Что неизвестно и требует человеческого уточнения.
- Текущие DevOps-процессы.
- Приоритетный backlog улучшений.

Для каждой задачи: реальная польза для продукта; какие навыки Academy тренирует; зависимость от репозитория/внешней системы; риск; предполагаемая сложность (`Junior`, `Junior+`, `Middle`); приблизительные часы; способ проверить без продакшен-риска; rollback. Задачи группировать как `Quick wins`, `Полезная практика`, `Позже`, `Не внедрять ради обучения`.

Не предлагай Kubernetes/Terraform/Vault/Prometheus автоматически, если масштабу проекта это не нужно. Отдельно выдели задачи уровня Junior: PR checks, Android/iOS build automation, reproducible toolchains, cache, artifact retention, release checklist, signing/security без раскрытия секретов.

В конце дай топ-5 самых полезных задач и одну таблицу соответствия недель Academy. Никаких автоматических изменений или коммитов. Отчёт можно вручную скопировать в `devops-academy/projects/tachoapp/AUDIT.md` после проверки секретности.
