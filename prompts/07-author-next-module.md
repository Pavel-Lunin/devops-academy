# Промпт 07 — Подготовить следующую порцию курса (переиспользуемый)

Роль: практикующий DevOps/Platform Engineer и образовательный методист. Работай в DevOps Academy, а не в TachoApp. Прочитай `AGENTS.md`, полный Junior/Middle roadmap, Syllabus нужного модуля, шаблоны, сделанные ранее качественные уроки и результаты настоящих занятий.

## Цель

Найди **следующие 2–3 ещё не готовых урока текущего модуля** (либо уроки того модуля, который явно укажу в сообщении). Создай только их; не генерируй материал на месяцы вперёд.

При создании не копируй автоматически уровень сложности соседних Middle-уроков: изначальная цель — Junior.

## Для каждого урока

- ID и конкретные prerequisites.
- Формулировка цели в виде проверяемого навыка.
- Зачем нужен инженеру и какой отказ помогает диагностировать.
- Теория простыми словами с точной терминологией, схема по необходимости.
- Работающий пример в выделенной учебной среде.
- Самостоятельное lab-задание (без ответа в том же файле), критерии проверки, минимум один сценарий с ошибкой, cleanup.
- Ответы/эталонный разбор в отдельном `solutions/` или answer-keys, которые наставник не раскрывает до попытки.
- Минимум 3 вопроса интервью с классификацией: определение, механизм, диагностика; более глубокие вопросы отдельно.
- Бесплатные источники и статус проверки реального URL.
- Время — включая чтение, упражнения, интервью и заметки, не превышая бюджет соответствующей недели.
- Отметка «готов/нужна проверка», отсутствие необъяснённых терминов.

## Методика

Знакомые TS/Git/CI основы не переписывай как курс для новичка, но обращай внимание на реальные пробелы. Для ARM64 проверяй доступность образов/инструментов. Не используй платные облака без разрешения. Не выполняй лабораторные задания за студента, не изменяй TachoApp. Не проставляй пройдено.

## Проверка качества

Перед завершением проверь структуру ссылок, prerequisites, наличие задач с проверяемыми критериями, уровень J0/J1/M и общий лимит часов. Если локально можно проверить статический пример безопасной командой, разрешается тестировать **эталонные** учебные примеры в изолированном окружении, но только с согласованием действий, которые создают/изменяют ресурсы. Не запускать lab от имени студента.

## Итог

Дай таблицу готовых уроков, фактические часы, найденные проблемы/непроверенные источники и следующий урок для пользователя. Не коммить автоматически.
