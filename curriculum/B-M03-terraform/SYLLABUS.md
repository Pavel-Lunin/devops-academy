# B-M03 — Terraform, state, IAM и границы Cloud

**Статус программы: черновик. Все перечисленные уроки и labs — запланировано; полнотекстовых уроков, готовых заданий и проверенной среды здесь нет.**

- Ступень: B; недели 36–38; глубина тем: M.
- Цель: Выделить модуль, обнаружить drift и аргументировать безопасную работу со state.
- Prerequisites: [B-M02-S01-L06](../B-M02-gitops/SYLLABUS.md#b-m02-s01-l06) — завершён предыдущий обязательный блок; при пробеле вернуть J0.
- Граница глубины: Без обязательных облачных расходов; локальная модель не выдаётся за cloud production.
- Бюджет: новая теория 9 ч; интервью 3 ч; самостоятельная lab 9 ч; диагностика/заметки 3 ч; всего 24 ч.
- Самостоятельно: обязательные J0-действия и их диагностика. J1: простой пример/знакомство; M только в B. Метки уточняются у каждого урока.
- Все команды в будущих labs будут иметь целевую ОС/архитектуру; sudo, deploy, удаления, host network и расходы не разрешаются этим планом. Учебная среда — локальная Linux ARM64, при необходимости несколько последовательно включаемых гостей.

<a id="lab-b-m03-s01-01"></a>
#### W36 / LAB-B-M03-S01-01 — Переиспользование Terraform

- Вход: теория недели B-M03-S01-L01–B-M03-S01-L03; для этапов с API используется уже построенный учебный проект; до W12 он не требуется.
- Контрольная точка 1, 60 мин: Выделить модуль из локального terraform_data примера без cloud provider.
- Контрольная точка 2, 60 мин: Проверить две синтетические конфигурации и отдельные state-пути без секретов.
- Контрольная точка 3, 60 мин: Разобрать diff/planned replacement и обосновать безопасный рефакторинг до apply.
- Артефакт: Локальный модуль, inputs/outputs и безопасный пересказ двух планов.
- Негативный кейс: Смешаны state окружений либо адрес ресурса неожиданно изменился.
- Критерий готовности навыка: Контракты модуля ясны, планы не применяются автоматически, state не попадает в Git.
- Ещё 60 мин практики: 30 независимая диагностика/ретест, 15 личная Markdown-заметка, 15 безопасная остановка/буфер.

#### W37 / LAB-B-M03-S01-02 — Cloud/IAM/network и remote state

- Вход: теория недели B-M03-S01-L04–B-M03-S01-L06; для этапов с API используется уже построенный учебный проект; до W12 он не требуется.
- Контрольная точка 1, 60 мин: По бесплатным документам одного провайдера описать IAM/network и границы расходов без создания ресурсов.
- Контрольная точка 2, 60 мин: Сравнить local backend с проектом remote backend на обезличенной схеме, указать непроверенные гарантии.

- Артефакт: Проект IAM/network/backend и наблюдение локальной блокировки; облачный backend не реализован.
- Негативный кейс: Общий state доступен лишним субъектам или конкурирующие операции не блокируются.
- Критерий готовности навыка: Чётко отделяет исполненную локальную часть от непротестированных remote/cloud предположений.
