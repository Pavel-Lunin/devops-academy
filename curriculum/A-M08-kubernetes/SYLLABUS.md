# A-M08 — Kubernetes fundamentals и troubleshooting

**Статус программы: черновик. Все перечисленные уроки и labs — запланировано; полнотекстовых уроков, готовых заданий и проверенной среды здесь нет.**

- Ступень: A; недели 24–27; глубина тем: J0/J1.
- Цель: Развернуть существующий API в локальном кластере и найти типовой сбой.
- Prerequisites: [A-M07-S02-L03](../A-M07-automation/SYLLABUS.md#a-m07-s02-l03) — завершён предыдущий обязательный блок; при пробеле вернуть J0.
- Граница глубины: Без HA control plane, разработки CNI/CSI, Helm/GitOps/Vault на этой ступени.
- Бюджет: новая теория 12 ч; интервью 4 ч; самостоятельная lab 12 ч; диагностика/заметки 4 ч; всего 32 ч.
- Самостоятельно: обязательные J0-действия и их диагностика. J1: простой пример/знакомство; M только в B. Метки уточняются у каждого урока.
- Все команды в будущих labs будут иметь целевую ОС/архитектуру; sudo, deploy, удаления, host network и расходы не разрешаются этим планом. Учебная среда — локальная Linux ARM64, при необходимости несколько последовательно включаемых гостей.

- Вход: теория недели A-M08-S01-L01–A-M08-S01-L03; для этапов с API используется уже построенный учебный проект; до W12 он не требуется.

`EXAM-A-M08` — запланировано: смешанная выборка уже изученных вопросов, одна самостоятельная типовая задача и один диагностический отказ. Условия без решений подготовит автор модуля; готового исполняемого экзамена ещё нет.
