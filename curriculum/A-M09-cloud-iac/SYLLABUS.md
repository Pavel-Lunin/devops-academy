# A-M09 — Cloud/IaC и Terraform intro без расходов

**Статус программы: черновик. Все перечисленные уроки и labs — запланировано; полнотекстовых уроков, готовых заданий и проверенной среды здесь нет.**

- Ступень: A; недели 28–29; глубина тем: J1.
- Цель: Объяснить VM/network/IAM и проверить локальный Terraform lifecycle.
- Prerequisites: [A-M08-S02-L06](../A-M08-kubernetes/SYLLABUS.md#a-m08-s02-l06) — завершён предыдущий обязательный блок; при пробеле вернуть J0.
- Граница глубины: Это не подтверждает опыт cloud apply, remote backend и production IAM.
- Бюджет: новая теория 6 ч; интервью 2 ч; самостоятельная lab 6 ч; диагностика/заметки 2 ч; всего 16 ч.
- Самостоятельно: обязательные J0-действия и их диагностика. J1: простой пример/знакомство; M только в B. Метки уточняются у каждого урока.
- Все команды в будущих labs будут иметь целевую ОС/архитектуру; sudo, deploy, удаления, host network и расходы не разрешаются этим планом. Учебная среда — локальная Linux ARM64, при необходимости несколько последовательно включаемых гостей.

### Самостоятельная практика и независимый результат

Это спецификация плана, не инструкция выполнения. Весь lab-блок — 3 × 60 минут по контрольным точкам ниже; подготовка среды входит в него. Из этих названий нельзя выводить, что ресурсы или проверки уже созданы.

<a id="lab-a-m09-s01-01"></a>
#### W28 / LAB-A-M09-S01-01 — Одно облако как модель

- Вход: теория недели A-M09-S01-L01–A-M09-S01-L03; для этапов с API используется уже построенный учебный проект; до W12 он не требуется.
- Контрольная точка 1, 60 мин: Нарисовать соответствие локального стенда VM/network/IAM на одном примере Yandex Cloud по бесплатной документации.
- Контрольная точка 2, 60 мин: Проверить синтетический список ресурсов на лишние права и возможные затраты без аккаунта.
- Контрольная точка 3, 60 мин: Подготовить локальную Terraform-конфигурацию на terraform_data без cloud credentials.
- Артефакт: Схема одного провайдера и черновик локальной HCL-модели.
- Негативный кейс: Широкая IAM-роль или «бесплатный trial» принят за отсутствие расходов.
- Критерий готовности навыка: Не создаёт аккаунт/платные ресурсы; объясняет предел доказательства локальной модели.
- Ещё 60 мин практики: 30 независимая диагностика/ретест, 15 личная Markdown-заметка, 15 безопасная остановка/буфер.

<a id="lab-a-m09-s01-02"></a>
#### W29 / LAB-A-M09-S01-02 — Локальный Terraform lifecycle

- Вход: теория недели A-M09-S01-L04–A-M09-S01-L06; для этапов с API используется уже построенный учебный проект; до W12 он не требуется.
- Контрольная точка 1, 60 мин: Проверить локальную модель и план без provisioners или внешнего provider.
- Контрольная точка 2, 60 мин: После отдельного разрешения изменения только учебного state либо по подготовленным наблюдениям сравнить change/no-op.
- Контрольная точка 3, 60 мин: Объяснить replacement и безопасное завершение; destroy автоматически не выполнять.
- Артефакт: HCL с синтетическими значениями, безопасный пересказ плана и запреты для state.
- Негативный кейс: Работа не из того каталога или неожиданная замена локального ресурса.
- Критерий готовности навыка: Знает init/plan/apply/destroy по назначению; наблюдавшийся локальный lifecycle не записывает как cloud deployment.
- Ещё 60 мин практики: 30 независимая диагностика/ретест, 15 личная Markdown-заметка, 15 безопасная остановка/буфер.
