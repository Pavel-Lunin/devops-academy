# Личные заметки

Заметок студента пока нет; ментор их не заполняет. Markdown доступен в VS Code и поиске, без Obsidian и внешней БД.

Предлагаемые имена: `YYYY-MM-DD-<ID-темы>-slug.md` для конспекта, `YYYY-MM-DD-incident-slug.md` для проблемы. Это примеры, не созданные записи.

В конспекте своими словами указать: что понял, зачем нужно, что попробовал, как проверил, что осталось неясным. Для команды записать ОС, место запуска, эффект и ограничение; не хранить пароли, токены, приватные адреса и корпоративные логи.

Для troubleshooting есть [шаблон заметки об инциденте](../templates/incident-note.md). Запись и диагностика входят в 1 час практики недели. Наличие конспекта само по себе не означает подтверждённый навык.
