# Лабораторные работы

В программе запланировано 45 лабораторных блоков. Подготовлены две офлайн-модели Networking: [LAB-A-M02-S01-01 — путь запроса](LAB-A-M02-S01-01-network-path/README.md) и [LAB-A-M02-S02-01 — IPv4 и маршруты](LAB-A-M02-S02-01-ipv4-routes/README.md). Они проверены на синтетических данных и не заменяют Linux-среду.

| Каталог | Содержание |
|---|---|
| [environments/](environments/) | Спецификации учебных сред; подготовлена ENV-01, офлайн-модель |
| [checks/](checks/) | Состояние независимых проверяющих средств |
| [solutions/](solutions/) | Эталонные решения; сейчас только каталог |

Остальные практические блоки находятся в syllabus соответствующих модулей. Время подготовки, выполнения, диагностики и очистки включено в [недельный бюджет](../docs/time-budget.md). Практика рассчитана на изолированную Linux-среду и синтетические данные; основной Mac и его сетевые настройки не являются учебной средой.
