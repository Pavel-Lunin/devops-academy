# Независимые проверки labs

Статус: **запланировано**. Проверяющих скриптов пока нет.

Будущая проверка связана с ID lab и оценивает наблюдаемый результат, а не совпадение последовательности команд с эталоном. Заранее указать ОС, зависимости, способ запуска, ожидаемый вывод и побочные эффекты. По умолчанию проверка читает состояние; изменения допускаются только по явно описанному контракту изолированной lab.

Автор проверяет инструмент на синтетических успешных и ошибочных состояниях: он не должен всегда возвращать успех, скрыто исправлять задание или раскрывать секреты и решение. Такой тест не считается выполнением lab студентом.

Фиксировать объём проверки в [отчёте](../../templates/verification-report.md); наличие текста скрипта не доказывает его работоспособность.
