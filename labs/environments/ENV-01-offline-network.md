# ENV-01 — Синтетический сетевой стенд

Статус: **проверено** для чтения Markdown и авторских вычислений; это модель, а не запущенная сеть.

## Назначение и границы

W03–W04: роли узлов, вложенность данных, ARP, IPv4 и маршруты без установки VM, захвата пакетов, платных ресурсов и изменения Mac. ARM64/x86 не влияют на бумажную модель; образов и плагинов нет. Она не подтверждает умение пользоваться Linux-интерфейсами и не заменяет будущую Linux-практику. Prerequisite A-M01 остаётся обязательным для основного маршрута.

Достаточно редактора Markdown на macOS Apple Silicon. Все адреса, имена и наблюдения в заданиях вымышлены. `198.51.100.0/24` и `203.0.113.0/24` обозначают документальные примеры, а не адреса для подключения. Ничего по ним не отправлять.

## Вычислительный пример

Необязателен для W03; W04 требует уже доступный Python 3.9+ со стандартной библиотекой `ipaddress`. Установка не входит в разрешение: если Python отсутствует, остановить вычислительный этап и обсудить среду. Команды запускают только авторский пример в памяти; сеть и файлы не меняются.

Место запуска: корень Academy, macOS ARM64; Linux ARM64 допускается после отдельной проверки наличия Python. Автор проверил Python 3.9/macOS ARM64 2026-10-18; Linux runtime не проверен. Ключ `-B` запрещает запись bytecode.

```sh
python3 -B scripts/network_examples.py layers
python3 -B scripts/network_examples.py subnet 192.0.2.139/26
python3 -B scripts/network_examples.py route
```

Первый пример показывает вложение условных объектов, не формирует реальные пакеты. Второй рассчитывает другую подсеть, не ответ самостоятельного задания; третий выбирает путь в отдельной фиксированной таблице.

## Самодиагностика и остановка

Если файл не найден, проверить открытую папку Academy; не менять PATH или системный Python. Если отсутствует `python3`, использовать бумажный маршрут W03, а W04 обсудить с ментором. Не копировать сюда реальные IP/MAC, hostname, VPN и корпоративные схемы.

После чтения закрыть редактор; после примера процесс завершается сам. Сервисов, VM, портов, временных сетей и обязательного удаления нет. Собственный ответ сохранить только по решению студента, без предзаполненной заметки. `sudo`, `ip`, `ss`, `ifconfig`, firewall и изменения маршрутов для этого стенда не нужны.
