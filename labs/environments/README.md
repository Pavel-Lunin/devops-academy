# Спецификации сред

Статус: **запланировано**. Подготовлена [ENV-01 — офлайн-модель](ENV-01-offline-network.md); она не предоставляет Linux VM или контейнер.

Основной учебный маршрут рассчитан на отдельную Linux-среду ARM64. Системные, привилегированные и сетевые опыты требуют подходящей VM; обычный контейнер не заменяет её для всех тем. Для сред важны архитектура образов и плагинов, ресурсы, границы сети, синтетические данные, остановка и очистка.

macOS-хост Apple Silicon не является целью экспериментов; его firewall и сетевые настройки в программу не входят. Конкретный runtime и версии для будущих labs пока не выбраны.
