# Спецификации сред

Статус: **запланировано**. Проверенной Linux-среды ещё нет; ничего устанавливать сейчас не требуется.

Каждая будущая среда получает `ENV-01` и [спецификацию](../../templates/environment.md): хост/гость, ARM64, доступные инструменты, лимиты ресурсов, сеть, синтетические данные, безопасная остановка и условия очистки.

Выбор VM/runtime и точных версий откладывается до подготовки lab и проверки доступных ресурсов Mac. Системное администрирование, systemd и опасные сетевые опыты требуют подходящей Linux VM; не предполагать эти возможности у обычного контейнера. Несовместимый amd64-образ должен иметь замену или явно описанный непроверенный вариант эмуляции.

Основной Mac не является мишенью экспериментов; его firewall и сетевые настройки не меняются. Общие ресурсы и неопределённые host mounts недопустимы без объяснения и отдельного согласования.
