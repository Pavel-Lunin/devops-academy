# LAB-A-M02-S02-01 — Эталонный разбор

Статус: **проверено** для синтетических условий. Авторский эталон для сопоставления с условиями задания.

## Часть 1

Маски /24=255.255.255.0, /26=255.255.255.192, /27=255.255.255.224; полное число адресов 256/64/32. `.130` из 10/8 и 172.31 из 172.16/12 — RFC1918; 172.32 не входит в RFC1918; 127.0.0.1 — loopback; 203.0.113.8 — документальный адрес. Gateway задаётся отдельно; loopback не адрес другого узла в LAN. Возможное объяснение расхождения — сравнение полученных параметров с исходной схемой без изменения хоста.

## Часть 2

10.24.9.130/26 → сеть10.24.9.128, broadcast .191, host .129–.190,62. 192.168.40.62/27 → сеть192.168.40.32, broadcast .63, host .33–.62,30. В первом блоке .190 внутри, .192 вне. C1: A видит B вне своего /26, B видит A в /24. Это разные решения о локальности, не доказательство полной недоступности. Запросить выбранные маршруты и наблюдение обратного пути; не обвинять DHCP без данных.

## Часть 3

10.24.9.150: /26 напрямую, next hop получатель. 203.0.113.70: /25 через .129;203.0.113.180: /0 через .190. Без /0 последнее назначение не имеет маршрута в данной модели. Оба заданных шлюза внутри локального /26 и допустимы как обычные адреса; наличие соответствия не доказывает их работоспособность.

DHCP выдаёт конфигурацию, routing выбирает путь, NAPT отображает адрес/порт. ACK и отображение без входящего наблюдения не доказывают ответ сервера. C2: допустимы отсутствие обратного пути, фильтрация, неработающий сервис и другие причинно связанные варианты. Требуется различающее наблюдение: например, наличие ответного пакета на границе против его отсутствия; конкретную причину без данных не назначать.

## Рубрика и дополнительная глубина

0 — объяснение не показано;1 — фрагменты с существенной ошибкой;2 — расчёты и причинные границы корректны;3 — самостоятельный новый вариант и диагностика. Не снижать за другие корректные гипотезы. Подсказки фиксируются при настоящем ответе, не здесь.

M отдельно, не экзамен J0: policy routing, несколько таблиц/равных маршрутов, NAT traversal. К ним не переходить автоматически после успешного `/26`.
