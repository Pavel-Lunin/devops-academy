# Отдельные эталонные решения

Статус: **каркас**. Эталонов пока нет.

Место будущего решения: `labs/solutions/<ID-lab>.md`. Автор может подготовить его отдельно от задания; ментор показывает полный разбор только после попытки и по запросу студента.

Не добавлять ссылки на решение непосредственно перед самостоятельным заданием и не выдавать его в выводе проверяющего скрипта. Отдельная папка защищает от случайного просмотра, но не ограничивает доступ технически.
