# TachoApp — граница будущего аудита

Статус: **запланировано**. В этом запуске TachoApp не исследовался, его файлы не читались и не менялись. По заданию это отдельный native Android/Kotlin и iOS/Swift проект; фактическая структура пока не подтверждена этим репозиторием.

## Как появится отчёт

Только отдельный запуск [промпта 05](../../prompts/05-tachoapp-readonly-audit.md) **в репозитории TachoApp**: локальный read-only аудит, без изменения Git/файлов, install/build, тестов с побочными эффектами и внешних действий. Отсутствие CI-файла не доказывает отсутствие внешнего CI.

Отчёт выводится в чат, не сохраняется в TachoApp. После проверки приватности студент сможет отдельно перенести допустимые сведения в `projects/tachoapp/AUDIT.md`; такого отчёта сейчас нет. Для публичного репозитория — только согласованные обезличенные выводы, без кода, данных, логов и узнаваемых конфигов продукта.

## Будущий список задач

`BACKLOG.md` создаётся только по результатам аудита, не на основании догадок. Для каждой задачи записать реальную пользу, доказательство из аудита, навыки Academy, зависимости, риск, сложность Junior/Junior+/Middle, часы, безопасную проверку и rollback.

Группы будущего списка: Quick wins → полезная практика → позже → не внедрять ради обучения. Потенциальные области для проверки, а не обнаруженные проблемы: воспроизводимость сборок, PR checks, агенты, cache/artifacts, безопасный выпуск и signing. Kubernetes/Terraform/Vault/Prometheus автоматически не предлагать.

Сам аудит не разрешает реализацию задач; изменения TachoApp требуют отдельного явного задания. [DevOps Lab](../devops-lab/README.md) остаётся независимой песочницей.
