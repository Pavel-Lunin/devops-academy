# TachoApp — отдельный проект

Статус: **запланировано**. TachoApp — отдельный native Android/Kotlin и iOS/Swift проект, не часть учебного DevOps Lab. В этой версии Academy его исходный код не исследовался; фактическая структура проекта не подтверждена.

Возможные темы будущего обзора: воспроизводимость сборок, PR checks, агенты, cache/artifacts, безопасный выпуск и signing. Это направления для рассмотрения, а не обнаруженные особенности проекта. В `projects/tachoapp/AUDIT.md` записей нет.

Учебные задачи курса и локальная практика описаны отдельно в [DevOps Lab](../devops-lab/README.md). Публичные учебные материалы не содержат код, данные, логи или узнаваемые конфигурации TachoApp.
