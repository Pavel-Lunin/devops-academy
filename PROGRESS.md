## Исходный профиль

По исходным сведениям: React Native CLI, TypeScript, JavaScript, HTML/CSS; эпизодически Kotlin/Swift. Ежедневный Git/Git Flow/PR. Небольшая практика Jenkins/Concourse, Linux- и macOS-агентов; знакомство с Nexus/Vault. Базовое знакомство с Docker/Compose/Linux; мало backend-практики. Сетевой фундамент заявлен как область для изучения с нуля. Среда: MacBook Apple Silicon, macOS, VS Code, Codex.
