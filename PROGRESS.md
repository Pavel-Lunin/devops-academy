## Исходный профиль — со слов студента

React Native CLI, TypeScript, JavaScript, HTML/CSS; иногда Kotlin/Swift. Ежедневный Git/Git Flow/PR. Небольшая практика Jenkins/Concourse, Linux- и macOS-агентов, знакомство с Nexus/Vault. Базовое знакомство с Docker/Compose/Linux; backend-практики мало. Сети требуют последовательного объяснения с нуля. Среда: MacBook Apple Silicon, macOS, VS Code, Codex.

Это входные сведения из задания, **не проверенные курсом навыки**; уверенный Git не нужно проходить заново.
