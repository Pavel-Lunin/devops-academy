# Текущее состояние программы

## Статус обучения

- Текущая последовательность сетевого трека из переписки: **NET-05**; **NET-01–NET-04 завершены**.
- Трек NET-xx ведётся отдельно от идентификаторов основной программы A-M02-Sxx-Lxx. Завершение NET-xx само по себе не засчитывает уроки, лабораторные или итоговую проверку A-M02.
- В [ROADMAP.md](ROADMAP.md) модуль A-M02 запланирован на недели 3–6. В [syllabus A-M02](curriculum/A-M02-networking/SYLLABUS.md) NET-04 по теме пересекается с A-M02-S02 (IPv4/CIDR), но не подтверждает выполнение всех её уроков и критериев. Статусы syllabus не менялись.
- Достоверная длительность занятий NET-01–NET-04 в переписке не указана; часы не подсчитаны.
- Заметки: [NET-01 — основы сетей](curriculum/A-M02-networking/notes/NET-01-theory.md), [NET-01 — диагностика Linux](curriculum/A-M02-networking/notes/NET-01-linux-network-diagnostics.md), [NET-04 — CIDR и IP-планирование](curriculum/A-M02-networking/notes/NET-04-cidr-ip-planning.md).

## Исходный профиль

По исходным сведениям: React Native CLI, TypeScript, JavaScript, HTML/CSS; эпизодически Kotlin/Swift. Ежедневный Git/Git Flow/PR. Небольшая практика Jenkins/Concourse, Linux- и macOS-агентов; знакомство с Nexus/Vault. Базовое знакомство с Docker/Compose/Linux; мало backend-практики. Сетевой фундамент заявлен как область для изучения с нуля. Среда: MacBook Apple Silicon, macOS, VS Code, Codex.
