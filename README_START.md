# DevOps Academy: набор промптов для Codex

Цель: самостоятельный переход React Native / TypeScript-разработчика в Junior DevOps и дальнейшее развитие к самостоятельным DevOps-задачам. Без Obsidian, с Markdown-заметками в VS Code.

## Как начать на Mac

1. Распакуй **содержимое** этого архива в пустой `~/Projects/devops-academy`.
2. Запусти терминал:

```bash
mkdir -p ~/Projects/devops-academy
cd ~/Projects/devops-academy
# Сюда распакуй содержимое архива (README_START.md, prompts/, resources/)
git init
codex
```

Если Codex CLI не установлен, смотри официальную инструкцию: https://github.com/openai/codex. Для запуска в уже открытом каталоге используется команда `codex`; при необходимости войди через свой ChatGPT-аккаунт. Можно также использовать Codex в VS Code или приложении Codex.

3. По очереди вставляй содержимое `prompts/01-...md`, затем `02`, `03`, `04`.
4. Просматривай созданные файлы и изменения через `git status` / `git diff`, затем самостоятельно коммить после проверки.
5. Промпт `05` запускай **только в репозитории TachoApp**, в режиме чтения. Никаких изменений там не разрешено.
6. Промпт `06` — рабочая команда для каждого занятия в DevOps Academy.
7. Промпт `07` — команда на подготовку **следующего**, а не всех, модулей.
8. Промпт `08` — контроль качества учебного плана и материалов по мере развития.

## Обязательные правила курса

- Ступень A — 30 недель × 8 часов = 240 часов; подготовка к типовым задачам Junior DevOps.
- Ступень B — дополнительные 15 недель × 8 часов = 120 часов; расширение до Junior+/основ Middle, но без обещания грейда.
- Неделя: 3 ч новая теория; 1 ч разбор и интервью; 3 ч лаборатория; 1 ч диагностика, фиксация заметок и проверка. Итого 4/4.
- Дополнительные недели при пробелах допустимы; **не жертвовать пониманием ради календаря**.
- Учебная лаборатория локальная и отделена от TachoApp. Не запускать платные ресурсы, деплой во внешние сервисы, опасные команды без разрешения.
- Все `*.md` содержат собственные заметки, поддаются поиску VS Code и версионированию через Git.
- После каждого раздела — практическая проверка и 5–10 вопросов интервью, далее повторение через 7 и 30 дней.
- Не копировать реальные корпоративные секреты/материалы в публичный учебный репозиторий.
- Два исходных текста пользователя включены в `resources/source-roadmaps/`; агент должен с ними ознакомиться. Прочие источники 2026 из предыдущего обсуждения агент должен проверить, если есть веб-доступ, иначе честно помечать непроверенными.

## Целевые этапы (ориентир, Codex уточняет в рамках бюджета)

### Junior — 30 недель
1–2 Linux CLI и организация лаборатории; 3–6 Networking + Security; 7–11 Linux administration + Bash; 12–14 Docker, 12-Factor, PostgreSQL basics; 15–16 Monitoring I; 17–20 CI/CD; 21–23 Ansible + небольшие скрипты; 24–27 Kubernetes basics; 28–29 Cloud + Terraform intro; 30 итоговая проверка.

### После Junior — 15 недель
31–33 Kubernetes deeper + Helm; 34–35 Argo CD + GitOps; 36–38 Terraform deeper + Cloud; 39–40 Secrets/Vault + supply chain; 41–42 Monitoring II, reliability; 43–44 integrated lab and incidents; 45 platform basics + interview rehearsal.

Темы уровня Middle не должны задерживать первую пробную Junior-собеседовательную оценку. Твёрдое знание Linux, Networking и диагностики важнее широты случайных инструментов.
